\posterbox[greenbox]{name=problem, column=1, between=row5 and row8}{
  {\sectionfont Why This Is Hard}\\[3pt]
  \bodyfont
  Minecraft resource packs are tiny repeated surfaces. A wrong edge, hue, or symbol is not hidden by scale; it tiles across the world.
  \vspace{3pt}
  \begin{itemize}
    \item Hundreds of hand-made block faces per pack.
    \item Vanilla filenames give alignment, but styles move nonuniformly.
    \item The task is not just low MAE: the tile must still read as the same material.
  \end{itemize}
}

  \smallbody

\posterbox[amberbox]{name=training, column=1, between=row13 and row17}{
  {\sectionfont Training Signal}\\[3pt]
  \bodyfont
  \[
    \mathcal{L}=\mathcal{L}_{noise}
    +\bar{\alpha}_t(0.70\mathcal{L}_{recon}
    +0.30\mathcal{L}_{grad}
    +0.20\mathcal{L}_{content})
  \]
  \begin{itemize}
    \item SNR weighting reduces unreliable \(x_0\) pressure at high noise.
    \item Content terms supervise source-relative structure, contrast, hue, and color moments.
    \item Source-close targets use a direct objective when target/content MAE \(\leq 0.045\).
  \end{itemize}
}

\posterbox[greenbox]{name=fit, column=1, between=row17 and bottom}{
  {\sectionfont Current Fit}\\[3pt]
  \bodyfont
  Best suited for vanilla-adjacent, minimalist, wood-family, and medium-complexity stylized materials.
  \vspace{3pt}
  \begin{itemize}
    \item Glass is limited because alpha is not modeled.
    \item Fine glyphs and repeated narrow bands need conservative routing.
    \item 64$\times$ art compressed to 32$\times$32 loses microtexture.
  \end{itemize}
}

\posterbox[bluebox]{name=model, column=2, between=row5 and row11}{
  {\sectionfont Two Models, Two Instincts}\\[2pt]
  \posterfig{0.93}{figures/spritecraft-dual-model-architecture.png}{StyleAwareUNet samples expressive candidates; RecolorNet predicts a residual that keeps vanilla structure legible.}
  \smallbody
  The useful split is behavioral: diffusion can invent style-specific texture, while recolor is the safety branch for symbols, line art, and hard structure.
}

\posterbox[lilacbox]{name=routing, column=2, between=row11 and row16}{
  {\sectionfont Selection Is the Model's Guardrail}\\[2pt]
  \posterfig{0.91}{figures/spritecraft-ensemble-routing-flow.png}{Candidate selection scores actual outputs rather than trusting a fixed branch.}
  \bodyfont
  \begin{itemize}
    \item Two stochastic diffusion samples are compared with recolor and fallback candidates.
    \item Structural quality checks edge fidelity, detail coherence, detail energy, and entropy.
    \item Style quality compares support references and change-from-vanilla magnitude.
  \end{itemize}
}

\posterbox[amberbox]{name=rules, column=2, between=row16 and bottom}{
  {\sectionfont What Changed in run39}\\[3pt]
  \bodyfont
  \begin{itemize}
    \item RecolorNet is trained for each current pack where available.
    \item High-pattern content raises the acceptance bar for diffusion outputs.
    \item Wood-family routing skips detail injection to preserve plank-line continuity.
    \item Bare Bones routes many samples through source-close training; stylized packs mostly keep the full content-aware objective.
  \end{itemize}
}

\posterbox[darkbox]{name=takeaways, column=3, between=row18 and bottom}{
  {\sectionfont Takeaways}\\[4pt]
  \bodyfont
  \begin{itemize}
    \item The strongest system is a routed ensemble, not a single generator.
    \item Easy packs need direct reconstruction; stylized packs need source-relative guidance.
    \item Better alpha handling, learned support ranking, and multi-resolution refinement are the next practical gains.
  \end{itemize}
}
